## Overview

The Mesonic Dataflow real-time pricing integration replaces catalog prices with live ERP prices for signed-in customers linked by customer number.

**Base URL:** `api/v1/apps/mesonic-dataflow-real-time-pricing/`

<Callout kind="info">
All endpoints require Bearer token authentication. See [Authentication](/authentication).
For filter syntax, pagination, and sorting, see [Common Patterns](/core-concepts/common-patterns).
</Callout>

<Callout kind="info" title="Full API reference">
For request/response schemas, see the [Mesonic real-time pricing API Reference](/api-reference/mesonic-dataflow-real-time-pricing).
</Callout>

## Settings

Group: `general`. The `api_key` is a secret used only to authenticate to the Mesonic Dataflow ERP API (sent as `X-Api-Key`); it is not returned in plain text for documentation examples.

<Expandable title="general — Settings Reference" default-open="true">

**general** — ERP Connection

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `enabled` | boolean | `false` | Enable real-time ERP pricing for linked customers. |
| `base_url` | text (URL) | — | Mesonic Dataflow API base URL. |
| `api_key` | password (secret) | — | ERP-issued API key for authenticated pricing requests. |

</Expandable>
