## Overview

The MediaHub manages polymorphic media associations, supporting images, videos, documents, and audio files. It provides full CRUD operations for media records with polymorphic relations to any parent model (e.g., Products, Companies), as well as a public CDN proxy endpoint for serving assets via Bunny CDN signed URLs.

**Base URL:** `api/v1/apps/media-hub/`

<Callout kind="info">
All media management endpoints require Bearer token authentication. See [Authentication](/authentication).
The CDN proxy endpoint is **public** and does not require authentication.
For filter syntax, pagination, and sorting, see [Common Patterns](/core-concepts/common-patterns).
</Callout>

## Media Library

The media library holds the uploaded files of your store. Each file belongs to one **collection** — a named folder such as `product-hub` or `invoice-hub`. Files uploaded by a hub land in that hub's collection; files uploaded without a collection land in `uncategorized`.

<Expandable title="List query parameters — GET /media" default-open="true">

| Parameter | Type | Notes |
|-----------|------|-------|
| `page`, `per_page` | integer | `per_page` max 500, default 25 |
| `search` | string | Matches the file name |
| `collection` | string | Exact collection name |
| `type` | string | `image`, `video`, `audio`, or `document`. `document` is every file that is not an image, video, or audio file |
| `mime_types[]` | string[] | Exact MIME types, e.g. `mime_types[]=application/pdf` |
| `created_from` | date `Y-m-d` | Uploaded on or after this day |
| `created_to` | date `Y-m-d` | Uploaded on or before this day (inclusive) |
| `sort_by` | string | `created_at`. Default order is newest first |
| `sort_dir` | string | `asc` or `desc` (default `desc`) |

An unknown `type`, `sort_by`, or `sort_dir`, or a malformed date, returns `400`.

</Expandable>

<Expandable title="Collections — GET /media/collections">

Returns every collection that holds at least one file, sorted by name. The `id` is the collection name.

```json
{
  "data": [
    { "id": "invoice-hub", "name": "invoice-hub", "count": 12 },
    { "id": "product-hub", "name": "product-hub", "count": 348 }
  ]
}
```

</Expandable>

<Expandable title="Update files — PUT /media">

| Field | Rules |
|-------|-------|
| `media` | required, array |
| `media.*.id` | required, integer |
| `media.*.name` | optional, string |
| `media.*.private` | optional, boolean |
| `media.*.collection` | optional, non-empty string, max 255. A name that does not exist yet creates the collection |

Moving a file keeps its `id` and URL. The batch is all-or-nothing: if any `id` is not a file of your store the request returns `404` and no file is changed.

</Expandable>

## Examples

<Steps>
  <Step title="Access a file via CDN proxy (public, no auth)">
    <Request tabs="cURL">
```bash
curl -s -X GET \
  'https://api.datahub.syncspider.com/api/v1/apps/media-hub/cdn/cdn.example-storage.com/products/images/product-42-hero.jpg'
```
    </Request>
  </Step>
  <Step title="List media for a specific product">
    <Request tabs="cURL">
```bash
curl -s -X GET \
  'https://api.datahub.syncspider.com/api/v1/apps/media-hub/media?filter[mediable_type]=[{"condition":"=","value":"Products"}]&filter[mediable_id]=[{"condition":"=","value":42}]&sort=sort_order' \
  -H 'Authorization: Bearer {token}' \
  -H 'Accept: application/json'
```
    </Request>
  </Step>
  <Step title="Filter primary images with includes">
    <Request tabs="cURL">
```bash
curl -s -X GET \
  'https://api.datahub.syncspider.com/api/v1/apps/media-hub/media?filter[media_type]=[{"condition":"=","value":"image"}]&filter[is_primary]=[{"condition":"=","value":true}]&include=mediable&per_page=50' \
  -H 'Authorization: Bearer {token}' \
  -H 'Accept: application/json'
```
    </Request>
  </Step>
  <Step title="Create a new media record">
    <Request tabs="cURL">
```bash
curl -s -X POST \
  'https://api.datahub.syncspider.com/api/v1/apps/media-hub/media' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json' \
  -d '{
    "mediable_type": "Products",
    "mediable_id": 42,
    "media_type": "image",
    "media_url": "https://cdn.example-storage.com/products/images/product-42-hero.jpg",
    "alt_text": "Product 42 hero image",
    "is_primary": true,
    "sort_order": 0
  }'
```
    </Request>
  </Step>
  <Step title="Set a media record as primary">
    <Request tabs="cURL">
```bash
curl -s -X POST \
  'https://api.datahub.syncspider.com/api/v1/apps/media-hub/media/15/primary' \
  -H 'Authorization: Bearer {token}' \
  -H 'Accept: application/json'
```
    </Request>
  </Step>
</Steps>
