## Overview

AiHub centralizes AI credentials and defaults for the installation. Other hubs call the shared AI wrapper. This page covers knowledge CRUD, Platform Assist sessions, Channel Assist admin connection, observability endpoints, and the **`general`** and **`channels`** App Settings groups.

**Base URL:** `api/v1/apps/ai-hub/`

<Callout kind="info">
All endpoints require Bearer token authentication (admin access). See [Authentication](/authentication).
For filter syntax, pagination, and sorting, see [Common Patterns](/core-concepts/common-patterns).
</Callout>

<Callout kind="info" title="Full API reference">
For request/response schemas, see the [AiHub API Reference](/api-reference/ai-hub).
</Callout>

## Settings

Group: `general`. Secrets such as `api_key` are masked on read.

<Expandable title="general — Settings Reference" default-open="true">

**general** — AI Configuration

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `enabled` | boolean | `true` | Master switch. When off, the AI wrapper refuses all calls. |
| `b2bware_ai_enabled` | boolean | `true` | Use the managed b2bWare AI account (overrides provider selection; usage-billed). |
| `provider` | select (`openai` / `anthropic` / `google` / `ollama` / `custom_url`) | `openai` | AI service when b2bWare AI is off. |
| `custom_endpoint` | text | `""` | Base URL for OpenAI-compatible APIs when provider is `custom_url`. |
| `api_key` | secret (masked) | `""` | Optional BYOK provider API key for OpenAI / Anthropic / Google. Stored securely; never returned in plain text. |
| `model` | text | `gpt-4o-mini` | Default model name; callers may override per request. |
| `global_instruction` | textarea | helpful B2Bware admin assistant prompt | System instruction prepended to every AI request. |
| `context_prompt` | textarea | page-context guidance | Extra text appended to the injected client context block. |
| `admin_assistant_enabled` | boolean | `true` | Platform Assist for admin users (may be overridden by `PLATFORM_ASSIST_ENABLED`). |
| `storefront_assistant_enabled` | boolean | `false` | Customer-facing storefront assistant. |
| `chat_history_retention_days` | select (`7` / `30` / `90` / `365` / `unlimited`) | `30` | How long Platform Assist chat sessions are kept. |

</Expandable>

Group: `channels`. Secrets are masked on read. Channel Assist stays off until `channels_enabled` is on and the installation AI wrapper is configured.

<Expandable title="channels — Settings Reference">

**channels** — WhatsApp and related admin channels

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `channels_enabled` | boolean | `false` | Turns Channel Assist on for this installation. |
| `channels_admin_base_url` | text | `""` | Public admin URL used for links sent on WhatsApp. No trailing slash. |
| `channels_whisper_api_key` | secret (masked) | `""` | Optional key for voice-note transcription. Falls back to the AI Hub OpenAI key. |
| `channels_easter_eggs_enabled` | boolean | `false` | Adds the configured persona to WhatsApp replies and confirm buttons. |
| `channels_agent_name` | text | `Q` | Name the WhatsApp agent uses for itself. |
| `channels_easter_egg_prompt` | textarea | Star Trek–inspired persona | Extra tone instructions, used only when Easter Eggs are on. |
| `channels_confirm_yes_button` | text | `Make it so!` | WhatsApp confirm button label (max 20 characters). |
| `channels_confirm_no_button` | text | `Abandon ship!` | WhatsApp cancel button label (max 20 characters). |
| `channels_intake_company_address_mode` | select (`always` / `never` / `ask`) | `always` | Whether PDF or assist input may fill a company address. |
| `channels_intake_contact_address_mode` | select (`always` / `never` / `ask`) | `never` | Whether a contact receives a company or PDF address. |
| `whatsapp_waba_phone_number` | text | `""` | WhatsApp Business number in E.164. Can also be supplied by the platform. |
| `whatsapp_phone_number_id` | text | `""` | Meta phone number id used to send messages. |
| `whatsapp_access_token` | secret (masked) | `""` | Meta access token for outbound WhatsApp messages. |
| `whatsapp_verify_token` | secret (masked) | `""` | Token Meta sends when it verifies the webhook. |
| `whatsapp_app_secret` | secret (masked) | `""` | When set, WhatsApp webhook posts without a valid signature are rejected. |
| `composio_api_key` | secret (masked) | `""` | Reserved for later Gmail and Slack channel support. |

</Expandable>
