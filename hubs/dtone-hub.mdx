## Overview

DTOneHub creates DT One transactions for digital top-up products. Admin routes cover configurations, transactions, and API logs. Storefront widget lookup/price endpoints use the Installation-Key header (no Bearer). A public webhook receives DT One callbacks.

**Base URL:** `api/v1/apps/dtone-hub/`

**Webhook:** `POST api/v1/webhooks/dtone/{installationKey}`

<Callout kind="info">
Admin endpoints require Bearer token authentication. See [Authentication](/authentication).
Storefront lookup routes are guest-accessible with Installation-Key; top-up checkout requires an authenticated shop customer.
For filter syntax, pagination, and sorting, see [Common Patterns](/core-concepts/common-patterns).
</Callout>

<Callout kind="info" title="Full API reference">
For request/response schemas, see the [DTOneHub API Reference](/api-reference/dtone-hub).
</Callout>

## Settings

Groups: `fulfillment`, `storefront`. API connection credentials are managed via `/settings/api`.

<Expandable title="fulfillment — Settings Reference" default-open="true">

**fulfillment** — Transaction Fulfillment

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `trigger_statuses` | select (multi) | `["paid", "processing", "completed"]` | Order statuses that create DT One transactions. |
| `trigger_on_order_created` | boolean | `false` | Also attempt at order creation when the initial status is already in `trigger_statuses`. |

</Expandable>

<Expandable title="storefront — Settings Reference" default-open="false">

**storefront** — Widget Checkout Billing Methods

Used by the embedded WOW top-up widget. Selected on-account methods bypass the normal checkout visibility gate for authenticated storefront customers only.

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `default_billing_method_id` | select | `null` | Billing method when the widget does not pass `billing_method_id`. Always permitted. |
| `topup_billing_method_ids` | select (multi) | `[]` | Additional billing method ids the widget may pass explicitly. |

</Expandable>
