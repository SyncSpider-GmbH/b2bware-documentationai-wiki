## Overview

The A1 Top-Up module posts voucher recharge requests to the A1 API when a LicenseKey reaches a configured status. This page documents **App Settings** only. See also [Hub Settings](/core-concepts/hub-settings).

**Base URL:** `api/v1/apps/a1-top-up-module/`

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/settings/groups/list` | List settings groups |
| GET | `/settings` | Get all settings |
| POST | `/settings` | Update settings |
| POST | `/settings/reset` | Reset all groups to defaults |
| GET | `/settings/{group}` | Get one group |
| POST | `/settings/{group}` | Update one group |
| POST | `/settings/{group}/reset` | Reset one group |

## Settings

Groups: `connection`, `trigger`, `default_mapping`, `retry`. Secrets such as `auth_password` are for Basic Auth only (purpose: authenticate to the A1 endpoint); they are not documented with sample values.

<Expandable title="connection — Settings Reference" default-open="true">

**connection** — A1 API Connection

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `base_url` | text (URL) | `""` | Full endpoint URL POSTed as-is (path included). |
| `auth_username` | text | `""` | Basic Auth username. |
| `auth_password` | password (secret) | `""` | Basic Auth password for the A1 endpoint. |
| `verify_ssl` | boolean | `true` | Verify the endpoint TLS certificate. |

</Expandable>

<Expandable title="trigger — Settings Reference" default-open="false">

**trigger** — LicenseKey status triggers

`post_success_status` must differ from `default_trigger_status` or the post-success update would re-fire the job.

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `default_trigger_status` | select | `activated` | LicenseKey status that dispatches the top-up job. |
| `post_success_status` | select | `used` | Status applied after a successful top-up. Empty keeps the current status. |

</Expandable>

<Expandable title="default_mapping — Settings Reference" default-open="false">

**default_mapping** — MSISDN, amount (chargingbon), and voucher PIN sources

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `msisdn_source` | select (`order_meta` / `customer_phone` / `attribute`) | `order_meta` | Where to read the customer phone number. |
| `msisdn_path` | text | `meta_data.mobile_number` | Dot-path in the order document when source is `order_meta`. |
| `msisdn_attribute_id` | select | `null` | AttributesHub attribute when source is `attribute`. |
| `amount_source` | select (`order_line_price` / `order_line_quantity` / `fixed` / `attribute` / `license_key`) | `order_line_price` | Where to read the top-up amount. |
| `amount_value` | number | `null` | Fixed amount when source is `fixed`. |
| `amount_attribute_id` | select | `null` | AttributesHub attribute when source is `attribute`. |
| `amount_license_key_field` | select | `null` | LicenseKey field when source is `license_key`. |
| `voucher_pin_source` | select (`license_key` / `attribute`) | `license_key` | Where to read the voucher PIN. |
| `voucher_pin_license_key_field` | select | `license_key` | LicenseKey field when PIN source is `license_key`. |
| `voucher_pin_attribute_id` | select | `null` | AttributesHub attribute when PIN source is `attribute`. |

</Expandable>

<Expandable title="retry — Settings Reference" default-open="false">

**retry** — Retry Policy

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `auto_retry_enabled` | boolean | `true` | Automatically retry failed top-up attempts. |
| `max_attempts` | number | `3` | Maximum attempts including the first. |
| `retry_backoff_seconds` | number | `60` | Seconds to wait between retries. |

</Expandable>
