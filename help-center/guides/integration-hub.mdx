## What this covers

**Integration Hub** is the in-app connector framework in B2Bware Admin (and optionally embedded in your ERP). Use these pages to configure integrations, run syncs, and host the UI outside DataHub.

<Callout kind="info" title="Not SyncSpider REST paste">
  Looking for wiring SyncSpider to DataHub REST upserts? That is a different path: [SyncSpider Integration](/help-center/guides/datahub-integration-setup).
</Callout>
