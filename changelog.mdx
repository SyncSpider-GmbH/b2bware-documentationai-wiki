<Update label="2026-06-01" description="MCP Server v1.11.0" tags={["feature"]}>

## B2Bware MCP Server v1.11.0

- **160 tools** — server-to-server Bearer auth for admin, integration, and operator analytics
- **Cart line-item API**: `add_cart_item`, `update_cart_item`; operator queries via `list_carts` / `list_orders`
- **Product media CDN ingest**: `main_image_file`, `main_image_fetch_url` on catalog tools
- **Variations**: `attach_variation_attributes`, `generate_product_variations`, `list_product_variations`; product types `license`, `dt-one`
- **New hub modules**: EventHub, RuleHub, SettingsHub, AutomationHub, DashboardHub (read-only), NotificationHub, LicenseHub, MediaHub
- **Bulk ops**: `bulk_update_stock`, `bulk_upsert_prices`; `create_order_comment`
- See [MCP Server](/ai-tools/mcp-server) for the full tool catalog

</Update>
