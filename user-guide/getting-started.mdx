## What you'll learn

- Open B2Bware Admin from the SyncSpider launcher or a direct URL
- Recognize workspace chrome: store label, language switcher, and **Go to store**
- Navigate the left sidebar hubs and use search to jump to a module

## Open B2Bware Admin

You can open Admin in either of these ways:

<Steps>
  <Step title="From the SyncSpider launcher">
    Sign in at [app.syncspider.com](https://app.syncspider.com), open the app launcher, and choose **B2Bware Admin**.

    <Image
  src="https://blob-cdn.documentation.ai/org-d7f30541-cdff-445d-a83f-48be426e0029/doc-ab18cb81-c197-4682-883d-2e8d54dd7f3f/1789404647501-wkrvtqjmgm7-login.png?fm=auto&auto=compress%2Cformat"
  alt="SyncSpider launcher with B2Bware Admin"
/>
  </Step>
  <Step title="From a direct URL">
    Go to:

    `https://datahub.syncspider.com/apps/b2bware/admin/dashboard`

    Bookmark this URL if you work in Admin daily.
  </Step>
</Steps>

<Callout kind="info" title="Access">
  You need an active SyncSpider account with permission for the B2Bware tenant. If Admin does not open, ask your workspace owner to grant access.
</Callout>

## Know your workspace

After you land on the dashboard, check the top of the screen:

<Image
  src="https://blob-cdn.documentation.ai/org-d7f30541-cdff-445d-a83f-48be426e0029/doc-ab18cb81-c197-4682-883d-2e8d54dd7f3f/1789404630146-4vv72qztiqa-01-dashboard.png?fm=auto&auto=compress%2Cformat"
  alt="B2Bware Admin dashboard with workspace chrome"
/>

| Element | What it does |
| --- | --- |
| **B2B Portal Demo Store** (or your store name) | Confirms which tenant workspace you are in |
| Language switcher | Changes the Admin UI language |
| **Go to store** | Opens the storefront for the current tenant |

<Callout kind="warning" title="Storefront URL">
  The storefront URL is tenant-specific. If **Go to store** opens a marketing site instead of your shop, ask your admin for the correct storefront URL for this workspace.
</Callout>

## Use search to jump to a module

When you know the module name, search is faster than scrolling the sidebar.

<Steps>
  <Step title="Open search">
    Focus the Admin search field (keyboard shortcut if your tenant enables one, or click the search control).
  </Step>
  <Step title="Type a module name">
    Enter a stable term such as **Products**, **Orders**, **Customers**, or **Settings**.
  </Step>
  <Step title="Open the result">
    Select the matching module to navigate there directly.
  </Step>
</Steps>
