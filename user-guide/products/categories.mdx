## What you'll learn

- Open **Categories** (`/admin/categories`)
- Add a category with **Add New Category**
- Read list columns and expand or collapse the tree

## Open Categories

<Steps>
  <Step title="Expand Products">
    In the left sidebar, expand **Products**.
  </Step>
  <Step title="Open Categories">
    Select **Categories**.
  </Step>
</Steps>

![Categories list](../../screenshots/products/categories.png)

## List columns and tree controls

| Column / control | Purpose |
| --- | --- |
| **Name** | Category name |
| **Image** | Category image |
| **Description** | Category description |
| **Product Count** | How many products sit in the category |
| **Hide** | Hide the category |
| **Expand All** / **Collapse All** | Expand or collapse the category tree |

## Add a category

<Steps>
  <Step title="Click Add New Category">
    On **Categories**, select **Add New Category**.
  </Step>
  <Step title="Complete the category">
    Set **Name**, **Image**, and **Description** as needed, then save with the action shown on that screen.
  </Step>
</Steps>

<Callout kind="info" title="Product Count">
  **Product Count** updates as you assign products to the category from product edit or related catalog flows.
</Callout>
