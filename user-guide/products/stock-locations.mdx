## What you'll learn

- Open **Stock Locations** (`/admin/warehouses`)
- Add a warehouse with **Add Warehouse**
- Read **Name**, **Location**, **Default**, and **Actions**

## Open Stock Locations

<Steps>
  <Step title="Expand Products">
    In the left sidebar, expand **Products**.
  </Step>
  <Step title="Open Stock Locations">
    Select **Stock Locations** (URL path `/admin/warehouses`).
  </Step>
</Steps>

{/* Screenshot pending upload: Stock Locations list (../../screenshots/products/stock-locations.png) */}

## List columns

| Column | Purpose |
| --- | --- |
| **Name** | Warehouse name |
| **Location** | Warehouse location |
| **Default** | Marks the default warehouse |
| **Actions** | Row actions for that warehouse |

## Add a warehouse

<Steps>
  <Step title="Click Add Warehouse">
    On **Stock Locations**, select **Add Warehouse**.
  </Step>
  <Step title="Enter Name and Location">
    Fill in **Name** and **Location**. Set **Default** if this warehouse should be the default.
  </Step>
  <Step title="Save">
    Confirm with the save action shown on that screen.
  </Step>
</Steps>

<Callout kind="info" title="Used on product Stock">
  Warehouses appear in **Select Warehouse** when you add stock on a product’s **Stock** tab.
</Callout>
