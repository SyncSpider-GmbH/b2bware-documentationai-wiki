## Open the module

<Steps>
  <Step title="Expand Products">
    In the left sidebar, expand **Products**.
  </Step>
  <Step title="Open Vendors">
    Select **Vendors**.
  </Step>
</Steps>

<Callout kind="info" title="Empty list">
  An empty Vendors list is normal on a fresh demo tenant. Create a vendor before linking it on a product.
</Callout>
