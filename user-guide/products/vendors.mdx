## What you'll learn

- Open **Vendors** under **Products**
- Add a vendor with **Add New Vendor**
- Recognize the empty state **No results found**

## Open Vendors

<Steps>
  <Step title="Expand Products">
    In the left sidebar, expand **Products**.
  </Step>
  <Step title="Open Vendors">
    Select **Vendors**.
  </Step>
</Steps>

![Vendors empty state](../../screenshots/products/vendors.png)

When no vendors exist, the list shows **No results found**.

## Add a vendor

<Steps>
  <Step title="Click Add New Vendor">
    On **Vendors**, select **Add New Vendor**.
  </Step>
  <Step title="Complete the vendor">
    Fill in the vendor fields shown on the form, then save.
  </Step>
</Steps>

<Callout kind="info" title="Empty list">
  A new workspace may show **No results found** until you create the first vendor with **Add New Vendor**.
</Callout>
