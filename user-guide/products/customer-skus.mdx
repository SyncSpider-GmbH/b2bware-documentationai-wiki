## Open the module

<Steps>
  <Step title="Expand Products">
    In the left sidebar, expand **Products**.
  </Step>
  <Step title="Open Customer SKUs">
    Select **Customer SKUs**.
  </Step>
</Steps>

<Callout kind="info" title="When to use Customer SKUs">
  Add a mapping when the buyer PO uses a different code than your internal SKU.
</Callout>
