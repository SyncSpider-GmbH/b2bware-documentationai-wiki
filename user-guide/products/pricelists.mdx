## What you'll learn

- Open **Pricelists** (`/admin/pricelists`)
- Create a pricelist with **New Pricelist**
- Deploy with **Deploy Selected** or **Deploy All**

## Open Pricelists

<Steps>
  <Step title="Expand Products">
    In the left sidebar, expand **Products**.
  </Step>
  <Step title="Open Pricelists">
    Select **Pricelists**.
  </Step>
</Steps>

![Pricelists list](../../screenshots/products/pricelists.png)

## List columns and actions

Toolbar:

- **New Pricelist**
- **Deploy Selected**
- **Deploy All**

Headers:

**ID**, **NAME**, **CODE**, **STATUS**, **CURRENCY**, **LAST DEPLOYED**, **CREATED AT**, **ACTIONS**.

## Create a pricelist

<Steps>
  <Step title="Click New Pricelist">
    On **Pricelists**, select **New Pricelist**.
  </Step>
  <Step title="Complete the pricelist">
    Set fields such as **NAME**, **CODE**, **STATUS**, and **CURRENCY** as shown on the form, then save.
  </Step>
</Steps>

## Deploy pricelists

<Steps>
  <Step title="Select rows (optional)">
    Select one or more pricelists when you want a partial deploy.
  </Step>
  <Step title="Deploy">
    Choose **Deploy Selected** for the selection, or **Deploy All** to deploy every pricelist.
  </Step>
</Steps>

<Callout kind="warning" title="Deploy carefully">
  **Deploy All** applies every pricelist. Prefer **Deploy Selected** when you only need a subset.
</Callout>
