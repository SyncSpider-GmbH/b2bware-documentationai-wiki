## What you'll learn

- Open **Edit Product** and move between tabs
- Update **General** fields and the product gallery
- Set **Price** and **Stock** for a product

## Open Edit Product

From **All Products**, open a product. You land on **General** at a path like `/products/1/general`.

Tabs across the top:

**General** · **Variants** · **Attributes** · **Price** · **SEO** · **Shipping** · **Stock** · **Cross Sell** · **Upsell**

Header actions on Edit Product: **Back**, **Preview**, **Duplicate**, **Update**.

## General

{/* Screenshot pending upload: Edit Product — General tab (../../screenshots/products/detail-general.png) */}

Use **General** for identity, gallery, and core catalog fields.

| Field / area | Purpose |
| --- | --- |
| **Product Gallery** | Product images |
| **Upload Images** | Add images to the gallery |
| **Name** | Product name |
| **Price** | Base price shown on General |
| **SKU** | Stock keeping unit |
| **Category** | Category assignment |
| **Brand/Manufacturer** | Brand or manufacturer |
| **Stock** | Stock summary on General |
| **EAN** | EAN code |
| **Status** | Product status |
| **Tax Class** | Tax class |
| **Description** | Full description |
| **Short Description** | Short description |
| **AI Translation** | AI-assisted translation |
| **Update** | Save General changes |

### Update General

<Steps>
  <Step title="Open General">
    Confirm the **General** tab is selected.
  </Step>
  <Step title="Upload or reorder images">
    Use **Upload Images** in **Product Gallery**. Drag images to change order when needed.
  </Step>
  <Step title="Edit fields">
    Set **Name**, **Price**, **SKU**, **Category**, **Brand/Manufacturer**, **Stock**, **EAN**, **Status**, **Tax Class**, **Description**, and **Short Description** as required.
  </Step>
  <Step title="Save">
    Select **Update**.
  </Step>
</Steps>

<Callout kind="info" title="Reorder photos">
  In **Product Gallery**, reorder photos so the primary image appears first before you select **Update**.
</Callout>

## Price

Open the **Price** tab (path segment `/stock-and-price`).

{/* Screenshot pending upload: Edit Product — Price tab (../../screenshots/products/detail-price.png) */}

| Control / field | Purpose |
| --- | --- |
| **Product Price** | Main price section |
| **Price** | Regular price |
| **Sales Price** | Sale price |
| **Sale Starts** | Sale start |
| **Sale Ends** | Sale end |
| **Cost Price** | Cost |
| **Profit** | Profit display |
| **See Tier Prices** | Open tier prices |
| **See Group Prices** | Open group prices |
| **Clear Sale Price** | Clear the sale price |
| **Update Product** | Save price changes |
| **Vatiants Prices** | Variant prices heading (label as shown in Admin) |

### Update price

<Steps>
  <Step title="Open Price">
    Select the **Price** tab.
  </Step>
  <Step title="Set Product Price">
    Enter **Price**, and optionally **Sales Price**, **Sale Starts**, **Sale Ends**, and **Cost Price**. Review **Profit**.
  </Step>
  <Step title="Optional: tiers and groups">
    Use **See Tier Prices** or **See Group Prices** when you need those price types. Use **Clear Sale Price** to remove an active sale.
  </Step>
  <Step title="Save">
    Select **Update Product**.
  </Step>
</Steps>

<Callout kind="warning" title="Vatiants Prices label">
  The Admin heading **Vatiants Prices** appears with that spelling on the Price screen. Use that exact label when matching the UI.
</Callout>

## Stock

Open the **Stock** tab (path segment `/stock`).

{/* Screenshot pending upload: Edit Product — Stock tab (../../screenshots/products/detail-stock.png) */}

| Control / field | Purpose |
| --- | --- |
| **Add New Stock** | Start a new stock row |
| **Select Warehouse** | Choose the warehouse |
| **Stock Quantity** | Quantity for that warehouse |
| **Add Stock** | Confirm the new stock row |

Example row you may see: **Default** with quantity **100**.

### Add stock

<Steps>
  <Step title="Open Stock">
    Select the **Stock** tab.
  </Step>
  <Step title="Add New Stock">
    Select **Add New Stock**.
  </Step>
  <Step title="Choose warehouse and quantity">
    Set **Select Warehouse** and **Stock Quantity**.
  </Step>
  <Step title="Confirm">
    Select **Add Stock**.
  </Step>
</Steps>
