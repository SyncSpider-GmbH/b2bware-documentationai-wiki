## Modules in this hub

| Module | What you use it for |
| --- | --- |
| **All Products** | Create and edit products, variants, media, prices, and stock |
| **Categories** | Organize products into a browsable tree |
| **Stock Locations** | Warehouses or sites that hold inventory |
| **Pricelists** | Price lists that drive contract and tier pricing |
| **Vendors** | Suppliers linked to products |
| **Customer SKUs** | Customer-specific product codes |

<Callout kind="info" title="Start with All Products">
  Most day-to-day catalog work starts in **All Products**. Use the other modules when you need structure (categories), inventory sites, pricing rules, vendors, or customer-specific SKUs.
</Callout>
