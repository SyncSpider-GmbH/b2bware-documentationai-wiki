## What you'll learn

- Where the **Products** hub lives in B2Bware Admin
- Which module to open for each catalog job
- How to jump to the detailed guides for each module

## Open the Products hub

Expand **Products** in the left sidebar to see every catalog module.

{/* Screenshot pending upload: Products hub expanded in the left sidebar (../../screenshots/products/sidebar-expanded.png) */}

| Module | Path | When to use it |
| --- | --- | --- |
| **All Products** | `/admin/products` | Create, find, import/export, and open catalog items |
| **Categories** | `/admin/categories` | Organize products into a category tree |
| **Stock Locations** | `/admin/warehouses` | Define warehouses and default stock locations |
| **Pricelists** | `/admin/pricelists` | Create and deploy pricelists by currency and status |
| **Vendors** | Vendors | Maintain supplier/vendor records for the catalog |
| **Customer SKUs** | Customer SKUs | Map customer-specific SKUs to your products |

<Callout kind="info" title="Start with All Products">
  Most day-to-day catalog work starts on **All Products**. Open a product from there to edit gallery, price, stock, and related tabs.
</Callout>

## Pick a module by job

| Job to be done | Go to |
| --- | --- |
| Add or find a product | [Manage products](/user-guide/products/manage-products) |
| Change name, price, or stock on one item | [Edit a product](/user-guide/products/edit-product) |
| Build or hide a category | [Categories](/user-guide/products/categories) |
| Add a warehouse | [Stock locations](/user-guide/products/stock-locations) |
| Create or deploy a pricelist | [Pricelists](/user-guide/products/pricelists) |
| Add a vendor | [Vendors](/user-guide/products/vendors) |
| Map a customer-specific SKU | [Customer SKUs](/user-guide/products/customer-skus) |
