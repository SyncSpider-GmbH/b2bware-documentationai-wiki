Fügen Sie Vendors hinzu, wenn Sie Lieferantenreferenzen auf Produkten oder in Beschaffungsabläufen brauchen.

  src="https://blob-cdn.documentation.ai/org-d7f30541-cdff-445d-a83f-48be426e0029/doc-ab18cb81-c197-4682-883d-2e8d54dd7f3f/1789404845075-wbudr57v0t-vendors.png?fm=auto&auto=compress%2Cformat"
  alt="Vendors — leerer oder Listenstatus"
/>

## Modul öffnen

<Steps>
  <Step title="Products aufklappen">
    Klappen Sie in der linken Sidebar **Products** auf.
  </Step>
  <Step title="Vendors öffnen">
    Wählen Sie **Vendors**.
  </Step>
</Steps>

<Callout kind="info" title="Leere Liste">
  Eine leere Vendors-Liste ist auf einem frischen Demo-Tenant normal. Legen Sie einen Vendor an, bevor Sie ihn auf einem Produkt verknüpfen.
</Callout>
