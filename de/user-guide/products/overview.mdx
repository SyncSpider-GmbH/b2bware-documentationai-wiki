## Module in diesem Hub

| Modul | Wofür Sie es nutzen |
| --- | --- |
| **All Products** | Produkte, Varianten, Medien, Preise und Bestand anlegen und bearbeiten |
| **Categories** | Produkte in einem browsbaren Baum organisieren |
| **Stock Locations** | Lager oder Standorte, die Bestand halten |
| **Pricelists** | Preislisten für Vertrags- und Staffelpreise |
| **Vendors** | Lieferanten, die mit Produkten verknüpft sind |
| **Customer SKUs** | Kundenspezifische Produktcodes |

<Callout kind="info" title="Starten Sie mit All Products">
  Die meisten täglichen Katalogaufgaben beginnen in **All Products**. Nutzen Sie die anderen Module, wenn Sie Struktur (Kategorien), Lagerorte, Preisregeln, Lieferanten oder kundenspezifische SKUs brauchen.
</Callout>
