## Was Sie lernen

- B2Bware Admin über den SyncSpider-Launcher oder eine direkte URL öffnen
- Die Arbeitsbereichs-Oberfläche erkennen: Store-Label, Sprachumschalter und **Go to store**
- Die Hubs in der linken Sidebar nutzen und per Suche zu einem Modul springen

## B2Bware Admin öffnen

Sie können Admin auf eine der folgenden Arten öffnen:

<Steps>
  <Step title="Über den SyncSpider-Launcher">
    Melden Sie sich unter [app.syncspider.com](https://app.syncspider.com) an, öffnen Sie den App-Launcher und wählen Sie **B2Bware Admin**.

    <Image
  src="https://blob-cdn.documentation.ai/org-d7f30541-cdff-445d-a83f-48be426e0029/doc-ab18cb81-c197-4682-883d-2e8d54dd7f3f/1789404647501-wkrvtqjmgm7-login.png?fm=auto&auto=compress%2Cformat"
  alt="SyncSpider-Launcher mit B2Bware Admin"
/>
  </Step>
  <Step title="Über eine direkte URL">
    Gehen Sie zu:

    `https://datahub.syncspider.com/apps/b2bware/admin/dashboard`

    Speichern Sie diese URL als Lesezeichen, wenn Sie täglich in Admin arbeiten.
  </Step>
</Steps>

<Callout kind="info" title="Zugriff">
  Sie benötigen ein aktives SyncSpider-Konto mit Berechtigung für den B2Bware-Tenant. Wenn sich Admin nicht öffnet, bitten Sie den Workspace-Inhaber um Zugriff.
</Callout>

## Den Arbeitsbereich kennenlernen

Nachdem Sie auf dem Dashboard gelandet sind, prüfen Sie den oberen Bildschirmbereich:

<Image
  src="https://blob-cdn.documentation.ai/org-d7f30541-cdff-445d-a83f-48be426e0029/doc-ab18cb81-c197-4682-883d-2e8d54dd7f3f/1789404630146-4vv72qztiqa-01-dashboard.png?fm=auto&auto=compress%2Cformat"
  alt="B2Bware-Admin-Dashboard mit Arbeitsbereichs-Oberfläche"
/>

| Element | Funktion |
| --- | --- |
| **B2B Portal Demo Store** (oder Ihr Store-Name) | Bestätigt, in welchem Tenant-Workspace Sie sich befinden |
| Sprachumschalter | Ändert die Sprache der Admin-Oberfläche |
| **Go to store** | Öffnet den Storefront des aktuellen Tenants |

<Callout kind="warning" title="Storefront-URL">
  Die Storefront-URL ist tenant-spezifisch. Wenn **Go to store** eine Marketing-Seite statt Ihres Shops öffnet, fragen Sie Ihren Admin nach der korrekten Storefront-URL für diesen Workspace.
</Callout>

## Per Suche zu einem Modul springen

Wenn Sie den Modulnamen kennen, ist die Suche schneller als das Scrollen in der Sidebar.

<Steps>
  <Step title="Suche öffnen">
    Fokussieren Sie das Admin-Suchfeld (Tastaturkürzel, falls Ihr Tenant eines aktiviert, oder klicken Sie auf die Suche).
  </Step>
  <Step title="Modulnamen eingeben">
    Geben Sie einen stabilen Begriff ein, z. B. **Products**, **Orders**, **Customers** oder **Settings**.
  </Step>
  <Step title="Ergebnis öffnen">
    Wählen Sie das passende Modul aus, um direkt dorthin zu navigieren.
  </Step>
</Steps>
